原则：P1 先保证**可靠、可追溯、可对账**，不追求最全最贵。P2/P3 增强数据待策略验证后再申请预算。

## 一期主备（免费 / 低成本）


| 角色       | 建议源             | 用途         | 费用  | 备注                       |
| -------- | --------------- | ---------- | --- | ------------------------ |
| 演示       | `demo`（本地 seed） | 基座验收       | 0   | 不得当交易主源                  |
| **主行情**  | baostock        | 日 K、日历、复权  | 0   | P1 第一个 DataSourceAdapter |
| **备用行情** | AkShare         | 同一标准表的第二源  | 0   | 跨源对账；主源失败可降级             |
| 可选增强     | Tushare         | 有 token 再用 | 按账号 | 独立验真 / `--peer tushare`；不作默认主源 |
| 不默认      | FTShare K 线     | 增强         | 需授权 | 实测 K 线被拒；只当 Adapter 可选项  |
| 明确后置     | 商业源             | 质量/覆盖补洞    | 付费  | 见未决                      |


优先级数字：主源 < 备源（`data_source.priority` 越小越优先）。未授权源 `auth_status` 不得为交易主源。

每次拉取：raw 原样落 `data/raw_data/`，记下 source、批次、耗时、行数，供 [data_contracts.md](data_contracts.md) 追溯。

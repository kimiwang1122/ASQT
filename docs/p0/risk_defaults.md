# 风控默认值

状态：**已确认**  
来源：分阶段实施 2.2；PRD 第 6 章  
修订：2026-09-03

策略可以更严，不能更松。更松必须改本文件并记版本。参数进入模拟盘后随 `strategy_version.risk_config` 固化。

## 账户级


| 规则     | 默认值                          | 说明                     |
| ------ | ---------------------------- | ---------------------- |
| 最大回撤告警 | 相对净值峰值 **-8%**               | 高优先级告警，不停机             |
| 最大回撤停机 | 相对净值峰值 **-12%**              | 禁止新订单，等同急停效果直到人工恢复     |
| 总仓位上限  | **95%**                      | 市值 / 总资产；保留现金缓冲        |
| 人工急停   | 全局 kill switch **优先于一切策略信号** | Pre-P0 仅有审计表；P3 必须可操作  |
| T+1    | **启用**                       | 回测与模拟必须一致              |
| 数据异常停机 | 任一 P0 质量闸门 `block` **禁止新订单** | P1 与 QualityChecker 联动 |


## 持仓与交易单位


| 规则     | 股票              | ETF                      |
| ------ | --------------- | ------------------------ |
| 单票仓位上限 | **10%**         | **20%**                  |
| 交易单位   | **100 股整数倍**    | 按该基金最小申赎/交易单位配置，缺省 100 份 |
| 单票止盈   | **+20%** 相对开仓成本 | 可按策略覆盖，须版本化              |
| 单票止损   | **-8%** 相对开仓成本  | 同上                       |


一期不做行业/主题集中度硬限制；若单票上限无法覆盖明显集中，P2 再加规则。

## 执行层硬规则（无参数可关）

- 停牌不交易
- 涨停不买、跌停不卖（按 `limit_suspension`）
- 重复订单靠 `idem_key` 拒绝
- 质量未通过不交易
- 急停后不得提交；恢复必须写原因并通过质检与风控检查



## 模拟盘费用假设（P3 用，P0 先冻结口径）


| 项   | 默认假设                     |
| --- | ------------------------ |
| 佣金  | 万分之 2.5，单笔最低 5 元         |
| 印花税 | 卖出 0.05%，买入 0            |
| 过户费 | 按沪市规则；深市 0（P3 实现时按交易所区分） |
| 滑点  | 先按 5 bp 成交价不利方向；可配置      |
| 撮合  | 默认次日开盘价；规则必须写入模拟配置       |

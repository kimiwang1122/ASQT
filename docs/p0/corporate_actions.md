# 已核实公司行为（复权闸门例外）

状态：**已核实后落地**  
修订：2026-09-04  
用途：只对「公告已核对、K 线与理论除权一致」的日期，抑制 `adj_conflict` 误报。不改 OHLC / `adj_factor`。

名单文件：`corporate_actions.csv`。`verified=1` 才参与闸门。

## 为何不能只用价格/因子比例

经验式：

`(前日未复权收盘 / 当日未复权收盘) ≈ (当日 adj_factor / 前日 adj_factor)`

**不是 100% 准确**，不能单独用来关告警：

1. **现金分红**也会改除权参考价和后复权因子，两边不必相等。
2. **除权日仍有涨跌**，未复权价不会刚好等于理论价。
3. **四舍五入、最小价位**会造成 1% 内偏差。
4. **源数据错误**也可能碰巧接近某个整数倍（如 2、3），会把坏数据放掉。
5. **只有现金、没有送转**时，因子几乎不动、股价小幅除息，与「大比例送转」不是一类事件。

因此必须 **多条件同时成立** 才抑制告警（见 `asqt/corporate_actions.py`）：

| 条件 | 要求 |
| --- | --- |
| 事件表 | `symbol + ex_date` 且 `verified=1`，送转后 `share_ratio > 1` |
| 因子 | `adj_factor` 倍数相对公告股本倍数偏差 ≤ 4%；若有现金分红放宽到 12% |
| 价格 | 收盘相对理论除权价的偏离不超过该标的涨跌停幅度 + 2% |
| 方向 | 送转后未复权收盘必须低于前收 |

A 股理论除权价（无配股）：

`(前收盘 − 每股现金红利) / (1 + 送股比例 + 转增比例)`

未命中事件表、或命中但价格/因子对不上：仍按原阈值 `warn≥1.5` / `block≥2.0` 报 `adj_conflict`。

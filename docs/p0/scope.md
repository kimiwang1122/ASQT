## 一期纳入


| 项    | 纳入                         | 说明                                       |
| ---- | -------------------------- | ---------------------------------------- |
| 交易品种 | A 股股票、境内指数型基金（ETF）         | 股票与 ETF 分池、分规则，不用股票字段硬套基金                |
| 频率   | 日频 / 中低频                   | 可支持日内多次信号，不追求 Tick / 毫秒级                 |
| 运行环境 | Mac 本地起步                   | 后续可迁云；QMT 若只能跑 Windows，执行网关单独部署          |
| 自动化  | 数据更新、质检、信号、模拟下单、告警         | 必须先经过模拟盘稳定期，才讨论实盘                        |
| 执行通道 | 先本地 PaperBroker            | QMT/XtQuant 接口预留，本阶段不接线                  |
| 数据   | 日 K、日历、主数据、复权、停牌、涨跌停、ST/退市 | 见 [data_contracts.md](data_contracts.md) |


## 一期明确不做

- 期货、港股、美股
- Level2、Tick、盘口深度、高频订单簿
- 承诺收益的自动实盘机器人
- 未过质量闸门时的研究/交易继续运行
- 在 P3 本地模拟盘稳定前接入 QMT 实盘或小资金实盘

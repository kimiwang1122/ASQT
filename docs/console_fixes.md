## 检查类型（字段码 → 中文）

接口仍返回英文码；控制台翻译。勿把同一码再开一条 C 类工单。

| 码 | 中文 | 含义 |
|---|---|---|
| missing | 缺失 | 缺字段、缺标的或日历开市日无 K |
| range | 越界 | OHLC 关系或价格/量额非法 |
| adj_conflict | 复权冲突 | 复权因子跳变且无已核实公司行为解释 |
| point_in_time | 时点错误 | 上市前/退市后仍有行情 |
| cross_source | 跨源不一致 | 主源与备源（或未复权价方向）对不上；`warn`，不单独阻断交易 |

## 调度入口（与 C9/C10 同一问题）

控制台右上角 **追加行情**：`POST /api/sync/runs`（异步）。  
服务进程内每个交易日 **16:30**（Asia/Shanghai）起轮询主源是否已有当日 K，齐了再追加并质检；**17:30** 起不再等待，与原先一样直到当天出现 `success` / `skipped`。`ASQT_SYNC_AUTO=0` 可关。  
记录页：`#sync`。  
进行中的同步占 SQLite 租约锁（`data_sync_lock` + `inflight=1`）；同库再点追加或 CLI `sync-daily` 返回占用（API 409）。不是 Redis；单机 SQLite 即跨进程互斥。租约 120 分钟过期可接管。

```bash
.venv/bin/asqt pull-daily --universe --append
.venv/bin/asqt sync-daily
```
